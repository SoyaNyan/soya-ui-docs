넓은 화면까지 이어지는 중단점

반응형 규칙은 모바일 우선 min-width 방식입니다. base에서 시작한 규칙은 sm → md → lg → xl → xxl 순서로 누적되며, 같은 속성은 더 큰 중단점의 클래스가 이어서 적용됩니다.

중단점은 물리 화면 픽셀이 아니라 브라우저 viewport의 CSS 픽셀을 기준으로 합니다. 기본 16px에서 xl은 1600 CSS px, xxl은 1920 CSS px입니다. 2560px QHD 화면도 배율 125%에서는 약 2048 CSS px이지만, 150%에서는 약 1707 CSS px이므로 xxl에 도달하지 않습니다. 브라우저 창과 도구 영역이 실제 viewport를 더 줄일 수 있습니다.

접근성은 핵심 계약입니다.

  • 제목 순서와 시각 크기를 분리해 의미 구조를 유지합니다.
  • 색상과 함께 텍스트, 경계와 상태 이름을 제공합니다.
  • 긴 레이블과 200% 텍스트에서도 페이지가 가로로 밀리지 않게 합니다.
  • 키보드 포커스가 고정 머리글에 가려지지 않게 합니다.
