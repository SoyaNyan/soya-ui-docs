속성

아래 항목은 패키지가 제공하는 공개 타입 계약입니다.

DataTable 공개 속성
속성타입기본값설명
rows필수TableRow[]—원본 행
columns필수DataTableColumn[]—표시, 검색, 정렬에 사용할 메타데이터와 셀 스니펫
rowKey(row:TableRow,index:number)=>string(row,index)=>String(row.id??index)원본 행의 식별값. 순서나 내용이 바뀔 수 있고 ID가 없는 행에는 명시해야 합니다.
captionstring—표의 접근 가능한 캡션
query양방향string''검색어
sort양방향TableSort—정렬 열과 방향
page양방향number11부터 시작하는 현재 페이지
pageSize양방향number20페이지당 행 수
selected양방향string[][]선택한 원본 행의 키
visibleColumns양방향string[]—표시할 열의 키. undefined이면 모든 열을 표시합니다.
selectablebooleanfalse행 선택 표시
searchLabelstring표 검색검색 입력의 접근 가능한 레이블
searchPlaceholderstring검색어를 입력하세요검색 입력의 자리표시자
columnsLabelstring표시 열열 선택 필드셋의 접근 가능한 이름
pageSizeLabelstring페이지당 행 수페이지 크기 선택의 접근 가능한 레이블
pageSizeOptionsnumber[][10,20,50]선택할 수 있는 페이지 크기
paginationLabelstring표 페이지 이동페이지 이동 영역의 접근 가능한 이름
selectColumnLabelstring선택선택 열 이름
rowSelectLabel(row:TableRow,index:number)=>string(_row,index)=>`${index+1}행 선택`각 행 선택 컨트롤의 접근 가능한 이름을 만드는 형식 함수
emptyLabelstring표시할 데이터가 없습니다.기본 빈 표 문구
noColumnsLabelstring표시할 열을 선택하세요.표시 열 없음 문구
previousPageLabelstring이전이전 페이지 버튼 문구
nextPageLabelstring다음다음 페이지 버튼 문구
filter(row:TableRow,query:string)=>boolean—사용자 정의 행 필터 함수
compare(left:unknown,right:unknown,column:DataTableColumn)=>number—사용자 정의 안정 정렬 비교 함수
emptySnippet—빈 결과 내용
onquerychange(query:string)=>void—검색어가 바뀔 때 호출하는 콜백
onsort(sort:TableSort|undefined)=>void—정렬이 바뀔 때 호출하는 콜백
onpagechange(page:number)=>void—페이지가 바뀌거나 유효 범위로 보정될 때 호출하는 콜백
onpagesizechange(pageSize:number)=>void—페이지 크기가 바뀌거나 유효 범위로 보정될 때 호출하는 콜백
onselect(selected:string[])=>void—선택값이 바뀔 때 호출하는 콜백
onvisiblecolumnschange(visibleColumns:string[])=>void—표시할 열이 바뀔 때 호출하는 콜백
classstring—루트 요소 배치용 클래스

상태

키보드와 포커스

  • 검색, 열 선택, 정렬, 행 선택, 페이지 크기와 페이지 이동은 각 네이티브 컨트롤 동작을 사용합니다.
  • 행을 필터링한 뒤 안정 정렬하고 페이지를 나누며, 선택 항목은 원본 행의 식별값을 유지합니다.
