컴포넌트

모든 공개 컴포넌트를 이름, 역할과 상태로 찾고 동작 예제와 타입이 명시된 API를 확인합니다.

입력과 선택

Button입력과 선택

폼을 제출하거나 즉시 실행할 작업을 시작합니다.

ButtonGroup입력과 선택

서로 관련된 행동을 하나의 조작 그룹으로 묶습니다.

Calendar입력과 선택

달력을 탐색하며 날짜 하나, 여러 날짜 또는 기간을 선택합니다.

Checkbox입력과 선택

독립적인 참·거짓 항목을 선택합니다.

ColorInput입력과 선택

색상 선택기와 HEX 값을 하나의 필드로 입력합니다.

Combobox입력과 선택

긴 선택지 목록을 검색해 하나의 값을 고릅니다.

Field입력과 선택

레이블, 설명, 오류와 입력 요소를 연결합니다.

IconButton입력과 선택

아이콘으로 표현한 단일 행동에 접근 가능한 이름을 줍니다.

Input입력과 선택

한 줄 텍스트와 네이티브 입력 값을 받습니다.

InputGroup입력과 선택

입력 앞뒤의 접두·접미 콘텐츠를 하나의 경계에 조합합니다.

InputOTP입력과 선택

일회용 인증 코드를 입력하고 붙여넣습니다.

Label입력과 선택

폼 제어 요소에 명시적인 이름을 연결합니다.

NativeSelect입력과 선택

플랫폼 기본 선택 메뉴로 정해진 값 하나를 고릅니다.

RadioGroup입력과 선택

서로 배타적인 선택지에서 하나를 고릅니다.

RangeInput입력과 선택

최소·최대 범위 안의 숫자를 슬라이더로 조절합니다.

Select입력과 선택

정해진 선택지에서 하나의 값을 고릅니다.

Switch입력과 선택

즉시 적용되는 설정을 켜거나 끕니다.

TagInput입력과 선택

여러 문자열 값을 태그 목록으로 입력하고 제거합니다.

Textarea입력과 선택

여러 줄의 긴 텍스트를 입력합니다.

Toggle입력과 선택

독립적인 누름 상태를 가진 버튼을 전환합니다.

ToggleGroup입력과 선택

관련 선택지를 하나 또는 여러 개 전환합니다.

표시

Alert표시

결과와 주의가 필요한 상태를 설명합니다.

Attachment표시

파일 정보와 업로드 상태 및 관련 동작을 표시합니다.

Avatar표시

사람이나 대상을 이미지 또는 대체 문자로 식별합니다.

Badge표시

짧은 상태나 분류를 본문 옆에 표시합니다.

BarChart표시

범주별 값을 막대로 비교하고 정확한 데이터를 함께 제공합니다.

Bubble표시

대화 내용을 발신 방향에 맞는 말풍선으로 표시합니다.

Card표시

관련 정보와 행동을 하나의 표면에 묶습니다.

DonutChart표시

전체를 이루는 항목의 비율을 도넛과 범례로 보여줍니다.

EmptyState표시

결과가 없는 이유와 다음 행동을 설명합니다.

Icon표시

이름으로 미리 정의된 SVG 아이콘을 표시합니다.

Kbd표시

키보드 키나 단축키 표기를 표시합니다.

LineChart표시

시간에 따라 변하는 수치의 추세를 선으로 보여줍니다.

Marker표시

흐름 안의 상태 변화나 사건을 간결한 표시로 구분합니다.

Message표시

대화 메시지의 발신자, 내용과 보조 정보를 배치합니다.

Separator표시

관련 영역 사이의 시각적 구분을 표시합니다.

Skeleton표시

콘텐츠 구조를 유지하며 불러오는 중 상태를 보여줍니다.

상호작용

Accordion상호작용

관련 섹션을 한 번에 하나 또는 여러 개 펼칩니다.

Collapsible상호작용

보조 콘텐츠 한 영역을 필요할 때 펼칩니다.

Command상호작용

검색 가능한 명령과 이동 항목을 실행합니다.

ContextMenu상호작용

대상 맥락에 맞는 보조 행동 메뉴를 엽니다.

Dialog상호작용

현재 흐름 위에서 상세 콘텐츠나 입력을 엽니다.

DropdownMenu상호작용

버튼에서 관련 행동 목록을 엽니다.

HoverCard상호작용

링크나 대상 위에 머물거나 포커스할 때 자세한 미리보기를 엽니다.

Popover상호작용

버튼 근처에 가벼운 비모달 콘텐츠를 엽니다.

Sheet상호작용

화면 가장자리에서 대화형 패널을 엽니다.

Tabs상호작용

같은 맥락의 콘텐츠 영역을 한 번에 하나씩 전환합니다.

Tooltip상호작용

키보드 포커스나 마우스를 올렸을 때 짧은 보조 설명을 제공합니다.

Pagination데이터

Table데이터

Spinner피드백

Toaster피드백

ToastProvider피드백
