사용법

앱에서는 패키지 최상위에서 공개한 항목만 가져옵니다.

속성

아래 항목은 패키지가 제공하는 공개 타입 계약입니다.

TagInput 공개 속성
속성타입기본값설명
idstring—입력 요소의 ID. 생략하면 SSR에 안전한 ID를 생성합니다.
values양방향string[][]중복되지 않는 태그 값
label필수string—접근 가능한 입력 이름
namestring—각 태그를 반복된 숨겨진 입력으로 직렬화할 폼 이름
placeholderstring값을 입력하고 Enter를 누르세요빈 입력 안내
disabledbooleanfalse입력과 폼 제출을 비활성화할지 여부
readonlybooleanfalse값 편집 차단
removeLabel(value:string)=>string(value)=>`${value} 삭제`각 삭제 버튼의 접근 가능한 이름을 만드는 형식 함수
onvalueschange(values:string[])=>void—태그 목록이 바뀔 때 호출하는 콜백
classstring—루트 요소 배치용 클래스

상태

  • default
  • populated
  • disabled
  • readonly
  • composing

키보드와 포커스

  • Enter는 문자 조합이 끝난 뒤 앞뒤 공백을 제거한 고유 값을 추가하고 폼 제출을 막습니다.
  • 빈 입력에서 Backspace는 마지막 태그를 제거하며 IME 조합 중에는 동작하지 않습니다.
  • 삭제 버튼은 Enter와 Space의 기본 동작을 사용합니다.
